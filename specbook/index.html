    Spec Book

    Connect your spec book

    Specs, ratings and photos save to a private GitHub repository. Clearing Safari, private browsing or a new phone can’t lose them. This takes about two minutes, once.

    1. Create a private repository named spec-book-data and tick “Add a README”. Open github.com/new
    2. Create a fine-grained token. Set expiration to the longest option, repository access to “Only select repositories” → spec-book-data, and Repository permissions → Contents to “Read and write”. Open token settings
    3. Paste the token below. It stays in this app and can only touch that one repository.
